# 전경준 (JeonKJ) — Portfolio (G3)

고2 때 만든 포트폴리오의 디자인 정체성(에메랄드 그린)을 유지하면서, 고3에 개발한 소프트웨어 프로젝트를 중심으로 새로 구성한 포트폴리오 웹페이지입니다.

## 구성

```
G3_pf/
├── index.html      # 페이지 전체 (콘텐츠 + JS 데이터 + 동작)
├── common.css      # 스타일 (CSS 변수 기반 / 라이트·다크 테마)
├── images/         # 선택: 프로필 사진·스크린샷 (없어도 정상 동작)
│   └── README.txt
└── README.md
```

순수 HTML/CSS/JS라 **빌드 과정이 필요 없습니다.** 파일 3종을 그대로 어디에 올려도 동작합니다.

## 섹션

| 섹션 | 내용 |
| --- | --- |
| 홈(Hero) | 소개 문구 + 핵심 지표(프로젝트 8 · 라이브 4 · 기술 15+) |
| 소개 | 자기소개, 관심 분야, 기술 스택 |
| 개발 프로젝트 | 고3 프로젝트 8개 (카드 → 모달: 기능·기술스택·기간·라이브 데모) |
| 활동 & 경험 | 고2 대회·동아리·도제 등 13개 활동 |
| 이력 | 학업·수상·NCS·언어·장학 + 주요 성과(특허 준비 등) |
| 연락처 | 이메일 |

## 로컬에서 보기

```bash
# 가장 간단한 방법 (Python 내장 서버)
cd G3_pf
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html`을 브라우저로 바로 열어도 되지만, 일부 브라우저 보안 정책 때문에 로컬 서버로 여는 것을 권장합니다.

## 사진/스크린샷 넣기 (선택)

- 프로필 사진: `images/profile.jpg` 로 넣으면 소개 섹션에 자동 표시됩니다. (없으면 🧑‍💻 아이콘)
- 프로젝트 스크린샷을 추가하고 싶으면 `images/README.txt` 참고.

## 배포

정적 파일이므로 아래 어디든 올릴 수 있습니다.

- **GitHub Pages**: 리포지토리에 올리고 Settings → Pages → 브랜치 선택
- **Firebase Hosting**: `firebase init hosting` → public 디렉터리를 `G3_pf`로 지정 → `firebase deploy`
- **Netlify / Vercel**: 폴더를 드래그 앤 드롭

## 데이터 수정

프로젝트·활동 내용은 `index.html` 하단 `<script>` 안의 `devProjects`, `activities` 배열만 고치면 됩니다. HTML 구조를 건드릴 필요 없이 카드가 자동으로 다시 그려집니다.
